# Selamat Datang 👋

Selamat datang di **Basic Programming Language (Python) Semester 1**.

Python merupakan salah satu bahasa pemrograman yang paling populer di dunia karena memiliki sintaks yang sederhana, mudah dipelajari, dan digunakan dalam berbagai bidang seperti Artificial Intelligence (AI), Data Science, Website Development, Game Development, Cyber Security, hingga Automation.

Pada semester ini kita akan mempelajari **dasar-dasar pemrograman** menggunakan Python. Materi disusun secara bertahap sehingga siswa yang belum pernah belajar coding sekalipun dapat mengikuti pembelajaran dengan baik.

Setiap pertemuan akan disertai dengan praktik langsung sehingga siswa tidak hanya memahami teori, tetapi juga mampu membuat program sederhana secara mandiri.
